# 归途 · 死后归来服务 — 需求与设计 v0.2

- 目标游戏：RimWorld **1.6**（当前安装 1.6.4871 public）
- 目标平台：Steam 创意工坊
- 版本说明：v0.1 是「人物保险」，v0.2 根据竞品 **RimInsurance（边缘保险）** 的实际情况重定位为「归来服务」
- 状态：需求确认中，确认后进入 M0 技术验证

---

## 0. 一句话

**不卖理赔，卖归来。** 按季度订阅「归途」，殖民者死亡后公司自动收走尸体，数日后把本人（伤痕累累地）送回来。
会员等级决定回保速度、伤势轻重，以及尸体被毁时能否仍然归来。

宣传语候选：**「别的保险赔你钱，我们赔你人。」**

---

## 1. 竞品分析：RimInsurance 已经把「保险」做完了

`3817669857` · Agenl · 2026-10-11 发布 · 215 订阅 · 1.6/1.7 · 中英双语 · 仅依赖 Harmony。

| 维度 | RimInsurance 的做法 | 我们的做法 |
|---|---|---|
| 核心动词 | **理赔（claim）** | **归来（return）** |
| 死亡后 | 玩家 7 天内申请，公司审核 0.1–1 天，可能拒赔 | 自动受理，无需操作 |
| 赔付物 | 白银 / 复活机械血清（**要求尸体存在**） | **人本身**（带伤回来） |
| 尸体没了 | 改赔白银 | 金卡以上仍可归来（灵魂定位） |
| 周期 | 15 天/季，等待期 1 天，宽限 1 天 | 15 天/季，自动续费 |
| 价格 | 保额 × 2.5%–9%/季 | 小人价值 × 2%/季（下限 150，上限 600） |
| 涨价 | 每次理赔 +15%，上限 +60% | 每次归来 ×1.5，上限 ×3 |
| 会员 | **无** | 累计消费三级，影响速度/伤势 |
| 公司 | 4 家，各 11 条合同文本 | 1 家（后续可扩） |
| 复杂度 | 高（拒赔率、合同条款、赔付比例、伤情系数） | **刻意低**（不填表、不选赔付、不读合同） |

**结论：不要做第二家保险公司。** 它已经把「投保—理赔」的每一个格子都填满了；正面竞争只会显得像换皮。
我们保留「保险」的世界观外壳，但把核心体验换成**一次有代价的归来**——这是它的数据结构里没有的东西。

**共存风险**：它 Harmony patch 了 `Pawn.Kill`（`Patch_Kill`），我们也需要。两者都是 postfix 的话通常不冲突，
但它检查「尸体是否存在」来决定能否赔复活针；如果我们把尸体 despawn 收走，可能影响它的判定。
MVP 阶段做兼容检测，必要时提供「尸体保留在原位」开关。

## 2. 核心循环

1. 在「归途」面板给殖民者订阅，按季度自动扣银。
2. 订阅有效期间死亡 → **公司自动收走尸体**（无需玩家操作），弹出「受理通知」信件。
3. 倒计时 3–6 天（会员等级决定）。
4. 「归来」事件：小人在地图边缘出现（黑卡可选空投），带复活病 + 永久疤痕 + 心情 debuff。
5. 归来后该小人的订阅费 ×1.5；会员累计消费增加。

**没有的东西**：理赔申请、审核、拒赔、赔付选择、保单额度、合同条款。玩家只需要决定「给谁订、订不订」。

## 3. 规则草案

| 项目 | 草案 | 说明 |
|---|---|---|
| 订阅周期 | 15 天（一个 quadrum） | 与竞品一致，玩家已熟悉 |
| 订阅费 | 小人市场价值 × 2%/季，下限 150、上限 600 银 | 高价值小人贵，但不会贵到离谱 |
| 扣费 | 每季度初自动从全殖民地白银扣 | 不足 → 1 天宽限 → 服务暂停（信件） |
| 自动续费 | 每个小人可单独开关 | 默认开 |
| 受理条件 | 死亡时订阅有效 | 宽限期内死亡 **不**受理（和竞品一致，避免白嫖） |
| 归来延迟 | 6 天（普通）/ 4 天（银卡）/ 3 天（金卡及以上） | 延迟是核心代价 |
| 归来位置 | 地图边缘走进来（黑卡可选空投舱） | 空投更有戏剧性，但要处理落地伤害 |
| 归来状态 | 复活病 5 天 + 永久疤痕 + 缺指/趾/耳概率 + 心情 −10 持续 10 天 | 用 `ResurrectionParams.gettingScarsChance` 打底 |
| 装备 | 随尸体一起回来（死时穿什么就穿什么） | 更像「人回来了」，不额外惩罚 |
| 涨价 | 每次归来订阅费 ×1.5，上限 ×3 | 防止无限复活 |
| 订阅中止 | 离开殖民地 / 被囚禁 / 失踪 → 自动退订，按天退费 | 边界情况 |
| 他人复活 | 若小人被复活针/仪式抢先救活 → 取消本次服务，退当期费用 | 防止复活两个 |
| 无尸体死亡 | 普通/银卡：不受理（信件说明「尸体未找回」）；金卡：50% 受理；黑卡：必定受理 | 会员价值的核心体现 |

## 4. 会员体系

按**累计订阅支出**（不是当前保额）计算，只升不降：

| 等级 | 累计消费 | 回保延迟 | 伤势 | 无尸体归来 |
|---|---|---|---|---|
| 普通 | < 1,500 银 | 6 天 | 2–4 处疤痕，25% 缺指/趾 | 不受理 |
| 银卡 | 1,500 | 5 天 | 2–3 处疤痕，15% | 不受理 |
| 金卡 | 6,000 | 4 天 | 1–3 处疤痕，10% | 50% 受理 |
| 黑卡 | 20,000 | 3 天 | 0–2 处疤痕，5% | 必定受理，每年 1 次 |

黑卡的「必定受理」用「灵魂定位」解释：尸体没了也能从数据层面把人拼回来——这正好是竞品合同里明确拒绝的情形。

## 5. MVP 范围 / 非目标

**MVP（第一个可发布版本）**
- 只服务**殖民者**
- 一个「归途」主面板：订阅状态、剩余天数、自动续费开关、累计消费/会员等级
- 季度自动扣费 + 欠费宽限 + 暂停提醒
- 死亡 → 自动收尸 → 倒计时 → 归来（带伤）
- 会员三级（只影响延迟和伤势，**不含**无尸体归来）
- 中英文文本

**非目标（后续）**
- 无尸体归来（黑卡特权，第二阶段）
- 多家公司、保险推销员、骗保事件
- 囚犯/访客/动物
- 与 Ideology 价值观联动（某些意识形态反感复活）
- 竞品的理赔/拒赔/合同系统——我们主动不做

## 6. 技术方案

已用反射核对 1.6.4871 程序集，关键 API 均存在：

| API | 签名 | 用途 |
|---|---|---|
| `RimWorld.ResurrectionUtility.TryResurrect` | `bool TryResurrect(Pawn, ResurrectionParams)` | 复活 |
| `RimWorld.ResurrectionParams` | `gettingScarsChance` / `restoreMissingParts` / `removeDiedThoughts` / `dontSpawn` | 控制伤势与落地 |
| `Verse.Pawn.Kill` | `void Kill(DamageInfo?, Hediff)` | 死亡拦截 |
| `Verse.Corpse.InnerPawn` | `Pawn` | 尸体里的本人 |
| `RimWorld.Planet.WorldComponent` | `.ctor(World)` / `WorldComponentTick()` / `ExposeData()` | 存档级数据 |

| 模块 | 做法 |
|---|---|
| 数据 | `WorldComponent_Guitu : WorldComponent, IExposable`，存订阅、归来队列、会员累计 |
| 死亡拦截 | Harmony `Pawn.Kill` postfix，判断订阅有效性；此时尸体已生成 |
| 收尸 | `corpse.DeSpawn()` 后用 `Scribe_Deep` 存进组件；**先验证跨存档可复活** |
| 归来 | `TryResurrect(corpse.InnerPawn, parms)` → `GenSpawn` 到地图边缘 → 信件 |
| 伤势 | `HediffMaker` + `HediffDefOf.Scar` / `MissingBodyPart`，按会员等级调概率 |
| UI | `MainTabWindow`（归途面板），列表 + 开关 + 会员进度条 |
| 计费 | `WorldComponentTick()`，每 900,000 ticks 结算一次（15 天） |
| 兼容 | 检测 `Agenl.RimInsurance` 是否加载；如加载则在面板提示潜在冲突 |

### 必须先验证的技术风险

1. **死亡小人的跨存档保存**：尸体 despawn 后 `Corpse.PostCorpseDestroy` 不会再触发，但读档后 `Scribe_Deep` 能否完整复原 `Pawn`？
   方案 A 保存尸体；方案 B 死亡瞬间做快照重建（丢关系）。**M0 先验证 A。**
2. **复活后的完整性**：技能、关系、记忆、装备是否保留；`ResurrectionParams` 各参数的实际效果。
3. **与 RimInsurance 共存**：两边都 patch `Pawn.Kill`，且它依赖尸体存在——需要实测。

## 7. 平衡与叙事

- **死亡仍然昂贵**：6 天延迟 + 永久疤痕 + 心情 debuff + 保费涨价，四条一起才有分量。
- **叙事是护城河**：竞品的合同文本非常强（4 家公司、13 万字符），我们拼不过文本量，就拼**归来的场景感**——
  归来信件、疤痕描述、家人的反应、小人自己的记忆。这些是「赔钱」系统永远做不到的。
- **反套路**：归来的人可以带一句「我不记得自己死了」的社交记忆，或对保险公司产生恐惧。

## 8. 验收标准

- [ ] 订阅 → 扣费 → 死亡 → 收尸 → 归来，全流程可跑通
- [ ] 存档/读档后订阅、归来队列、会员累计不丢
- [ ] 欠费、退订、宽限期、被他人复活等边界正确
- [ ] 归来小人的名字、技能、关系、装备与原小人一致
- [ ] 与 RimInsurance 同时加载不红字（至少不互相破坏）
- [ ] 中英文文本无缺键
